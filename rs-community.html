GENERIC HTTPS NEURAL TTS API PROTOCOL (/audio_query & /synthesis)

VECTRA RS のカスタム音声クライアントは、2フェーズRESTエンドポイント仕様に準拠した任意の自己ホスト型・クラウド型ニューラルTTS推論サーバーと通信可能です。

The VECTRA RS audio engine communicates with any self-hosted or cloud neural TTS inference server implementing the standard two-phase REST synthesis contract below.

PHASE HTTP METHOD & PATH QUERY PARAMETERS RESPONSE CONTENT-TYPE
STEP 1: QUERY POST /audio_query ?text={UTF8_URL_ENCODED}&speaker={INT} application/json (Acoustic Parameters)
STEP 2: SYNTH POST /synthesis ?speaker={INT} (Body: STEP 1 JSON) audio/wav (RIFF PCM 16-bit Mono/Stereo)
CURL VERIFICATION COMMAND (2-STEP PIPELINE TEST) 
# Step 1: Generate Acoustic Query JSON
curl -s -X POST "https://your-tts-endpoint.example.com/audio_query?speaker=1" \
  --get --data-urlencode "text=およそ300メートル先、斜め左方向です。" > query.json

# Step 2: Synthesize RIFF WAV Audio Stream
curl -s -X POST "https://your-tts-endpoint.example.com/synthesis?speaker=1" \
  -H "Content-Type: application/json" \
  -d @query.json > nav_test.wav

SSL / Cloudflare Tunnel セキュア構成ガイド ＆ 疎通テスター

SSL / CLOUDFLARE TUNNEL CONFIGURATION & ENDPOINT TESTER

Android セキュリティポリシー（usesCleartextTraffic="false"）に準拠するため、VECTRA RS は平文HTTP（http://）を遮断し、有効なTLS証明書を持つ HTTPS（https://）エンドポイントのみ を許可します。ローカル推論サーバーを公開ポート開放なしでHTTPS化する場合は、Cloudflare Tunnel またはリバースプロキシをご使用ください。

In strict compliance with Android security policies (usesCleartextTraffic="false"), VECTRA RS rejects cleartext HTTP traffic and requires a valid TLS HTTPS (https://) endpoint. Use Cloudflare Tunnel or a TLS reverse proxy to expose local inference servers securely without opening router ports.
