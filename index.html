INSTALLATION PROTOCOL

スタンドアロンAPKの導入手順
Google Play プロテクト警告の突破方法（重要） MUST READ

本アプリはGoogle Playストア公開前の「先行クローズドβ専用ビルド（独自署名APK）」です。そのため、インストール時にAndroid標準のPlayプロテクト確認画面が表示されますが、ウイルスや不正プログラムではありません。以下の3ステップで導入してください。

STEP 01

GoogleドライブからAPKを保存し「不明なアプリのインストール」を許可

上部の DOWNLOAD APK ボタンからGoogleドライブを開き、「ダウンロード（スマホへ保存）」を実行します。保存したAPKを開き、初回のみ「この提供元のアプリをインストール」の設定画面が開く場合は、スイッチを ON（許可） にして戻ります。

STEP 02

Playプロテクト画面で「詳細」➔「インストールする」を選択

「アプリをスキャンしますか？」または「安全ではないアプリがブロックされました」と表示された場合は、画面内の 「詳細（More details）」 をタップし、下部に現れる 「インストールする（安全ではないアプリをインストール）」 をタップしてください。

STEP 03

位置情報（GPS）権限の許可

VECTRA起動後、位置情報へのアクセス許可を求められたら 「アプリの使用中のみ許可」（かつ「正確な位置情報」をON）を選択してください。

03

FREE-DRIVE HIGHWAY HUD

ナビ無しで使える高速道路施設モード
目的地設定不要。高速本線に乗るだけで前方施設を自動ロックオン CORE FEATURE

いつもの道やドライブで「ルート案内（道案内）は要らないけれど、次のSA/PAやICまでの距離と到着時刻だけ知りたい」という場面に最適化されたVECTRAのコア機能です。ナビ回数を一切消費せず、完全無制限で利用できます。

// HOW TO ACTIVATE

1. 画面右側の ROUTE HGWY スイッチが左側（HGWY）になっていることを確認します。

2. 高速道路・都市高速の本線走行中に HIGHWAY MODE スイッチをONにすると、進行方向の路線（首都高C1等の環状線周回にも完全対応）を自動解析し、直近3つの施設を下から上へ積み上げ表示します。

※施設名の表記は、日本語（デフォルト）と英語（欧州車コックピット風）をいつでもワンタップで切り替え可能です。

04

TACTICAL ROUTE & ALT SWITCH

ルート案内と2段階ステルス代替ルート
2通りの目的地セットと、運転を妨げない「2段階ステルス代替ルート」 SMART ROUTING
METHOD A

キーワード検索（左下「🔍」ボタン）

画面左下の虫眼鏡アイコンをタップし、施設名や住所を入力して検索します。候補をタップすると即座にルート計算・案内が開始されます。

METHOD B

マップ長押しダイレクトピン留め（検索回数消費ゼロ）

地図上の行きたい場所を 約1秒間長押し（ロングタップ） すると、赤いピンが刺さり、検索枠を消費せずにダイレクトにその地点へのナビを開始します。

STEALTH ALT

代替ルート（ALT ROUTE）の2段階切り替えギミック

ルート案内中、分岐可能な別ルートが存在すると画面右下に半透明の ALT ROUTE 1/2 | -3 min ボタンがステルス待機します。
・1タップ目（Wake Up）：ボタンが鮮明化し、地図上の分岐ルート上に「到着予想時刻（ETA）・時間差・距離差」の吹き出しが出現します（4秒間放置すると自動で元のステルス状態へ戻ります）。
・2タップ目（Confirm Switch）：起き上がったボタン（または地図上の吹き出し）をもう一度タップすると、即座にその代替ルートへ切り替わります！

HUD & TRAFFIC CUSTOMIZATION

画面コントロールと設定メニュー
渋滞ラインのリアルタイム太さ調整 ＆ カメラ制御 SETTINGS HUD
ボタン / 設定項目 配置場所 機能・動作詳細
コンパスボタン 左下（1段目） タップするごとにカメラ視点を NORTH-UP 2D（北固定） ➔ HEAD-UP 2D（進行方向上） ➔ HEAD-UP 3D（3D俯瞰） の順で切り替えます。
レイヤー切替ボタン 左下（2段目） 昼夜トラフィック・ダーク・サテライト（航空写真）など 全7種類のマップスタイル をワンタップで巡回切り替えします。
自車3Dロックボタン 左下（3段目） 地図をスクロールして現在地から離れた際、ワンタップで自車位置の HEAD-UP 3D 追従モードへ即座に戻します。
Traffic Line Width 設定（⚙️）内 地図上の渋滞情報ライン（緑・橙・赤・暗赤）の太さを 0.5x 〜 2.0x のスライダー、または THIN / STD / BOLD プリセットでリアルタイムに調整・保存できます。
Map / Voice Language 設定（⚙️）内 地図ラベルおよび高速施設リスト・音声案内の言語を 日本語（JA：デフォルト） と 英語（EN：欧州車純正コックピット風） からいつでも切り替えできます。
HUD Opacity 設定（⚙️）内 上下のHUDパネルおよび高速施設リストの背景透過度を 85% / 75% / 70% から好みに合わせて切り替えられます。
