INSTALLATION PROTOCOL

スタンドアロンAPKの導入・アップデート手順
Google Play プロテクト警告の突破方法（重要） MUST READ

本アプリはGoogle Playストア一般公開前の「先行クローズドβ専用ビルド（独自署名APK）」です。初回導入時および新バージョンへの上書きアップデート時は、以下の3ステップでインストールしてください（※すでに旧版を導入済みの場合は、アンインストールせずそのまま上書きインストール可能です）。

STEP 01

GoogleドライブからAPKを保存し「不明なアプリのインストール」を許可

上部の DOWNLOAD APK ボタンからGoogleドライブを開き、「ダウンロード（スマホへ保存）」を実行します。保存したAPKを開き、初回のみ「この提供元のアプリをインストール」の設定画面が開く場合は、スイッチを ON（許可） にして戻ります。

STEP 02

Playプロテクト画面で「詳細」➔「インストールする」を選択

「アプリをスキャンしますか？」または「安全ではないアプリがブロックされました」と表示された場合は、画面内の 「詳細（More details）」 をタップし、下部に現れる 「インストールする（安全ではないアプリをインストール）」 をタップしてください。

STEP 03

位置情報（GPS）権限の許可 ＆ フォントエンジンの自動最適化

VECTRA起動後、位置情報へのアクセス許可を求められたら 「アプリの使用中のみ許可」（かつ「正確な位置情報」をON）を選択してください。初回起動時にVECTRA専用の和欧混植ボールドフォントが自動キャッシュされ、どのスマホ機種でも100%統一されたコックピットHUDが描画されます。

03

RUNNER'S MODE // SHUTOKO & HIGHWAY HUD

目的地不要の「走り屋モード」＆ 高速施設レーダー
RUNNER'S MODE // FREE-DRIVE LOCK-ON ZERO QUOTA CONSUMPTION
「どこへ行くか」じゃない。「今、どのコーナーとJCTの先に何があるか」だけを射抜く。

既存のスマホナビには致命的な弱点があります。それは「目的地を設定しないとただの地図になること」、そして「首都高C1などの環状線を1周すると到着扱いになって案内が消えること」です。
VECTRAのコア機能である『走り屋モード（FREE-DRIVE HIGHWAY HUD）』は、目的地設定を一切必要としません。高速本線に乗った瞬間、自車の速度と進行方向ベクトルから走行中の路線（C1内回り/外回り、湾岸線、新東名など）をリアルタイムにロックオンし、何周ループしても前方のIC・JCT・PAまでの距離と通過予想時刻（ETA）を無限にスタック表示し続けます。

// SHUTOKO C1 & BAYSHORE TACTICAL RADAR LOCK-ON: ACTIVE
VECTOR TRACKING: 360° REALTIME C1 / WANGAN / AQUA-LINE / TOHOKU / TOMEI
01 // 首都高C1・環状線の「エンドレス周回」完全対応

C1（都心環状線）の内回り・外回りを何周ループしても、進行方向ベクトルから次に来るIC・JCTを自動で再ロックオン。ルーレット走行中に案内が途切れることは一切ありません。

02 // JCT分岐後の路線スイッチにも0.5秒で即応

例えば「C1から浜崎橋JCTで11号台場線へ抜け、レインボーブリッジを渡って湾岸線（大黒PA・辰巳PA方面）へ入る」といったルート変更も、ハンドルを切った瞬間に前方路線を再解析してリストを書き換えます。

03 // 夜間コックピットに溶け込む「自動減光ステルスUI」

操作しない時はトグルスイッチ類が自動で半透明（50%減光）へフェードし、視界の邪魔をゼロに。スポーツ走行時のコックピット計器として機能します。

QUICK PIN, ROUTE & ALT SWITCH

お気に入り3拠点ドロワーと2段階ステルス代替ルート
3通りの目的地セットと、運転を妨げない「2段階ステルス代替ルート」 SMART ROUTING
NEW // QUICK PIN

画面左端「U字プルタブ」によるお気に入り3拠点（Home / favolit1 / favolit2）ワンタップ出発

画面左端（コンパスボタンのすぐ上）に配置された「横向きU字タブ（絆創膏の端っこ風タブ）」を指で右へ引っ張り出す（またはタップする）と、3つの専用拠点スロットが出現します（5秒間で自動収納）。

[Home] [favolit1] [favolit2]
⋮⋮

・未登録スロットをタップした場合：画面中央に赤い「＋」照準と透過アナウンス（例：Home 設定中）が表示されます。地図を動かして自宅やよく行くPA/集合場所に「＋」を合わせ、「決定」を押すだけで記憶されます。
・登録済みスロットをタップした場合：検索回数を一切消費せず、1タップで即座にその拠点へのルート案内を開始します！（位置の変更や長押し消去は設定メニュー⚙️からいつでも行えます）

METHOD A

キーワード検索（左下「🔍」ボタン）

画面左下の虫眼鏡アイコンをタップし、施設名や住所を入力して検索します。候補をタップすると即座にルート計算・案内が開始されます。

METHOD B

マップ長押しダイレクトピン留め（検索回数消費ゼロ）

地図上の行きたい場所を 約1秒間長押し（ロングタップ） すると、赤いピンが刺さり、検索枠を消費せずにダイレクトにその地点へのナビを開始します。

STEALTH ALT

代替ルート（ALT ROUTE）の2段階切り替えギミック

ルート案内中、分岐可能な別ルートが存在すると画面右下に半透明の ALT ROUTE 1/2 | -3 min ボタンがステルス待機します。
・1タップ目（Wake Up）：ボタンが鮮明化し、地図上の分岐ルート上に「到着予想時刻（ETA）・時間差・距離差」の吹き出しが出現します（4秒間放置すると自動で元のステルス状態へ戻ります）。
・2タップ目（Confirm Switch）：起き上がったボタン（または地図上の吹き出し）をもう一度タップすると、即座にその代替ルートへ切り替わります！
